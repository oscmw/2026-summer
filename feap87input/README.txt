The various directories contain numerous test problems that you can run.  Each will run a problem (or a few), make a plot, and then stop in interactive mode allowing you to examine the solution.  Optionally you can run testex by sourcing the file, "source testex", at the command prompt and this will run all the problems in non-interactive mode, one after the other.  Note if feap is not on your path you will need to alias feap to your executable.
